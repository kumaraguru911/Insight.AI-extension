## 🚀 HOW TO USE

### Start the Feature
```
1. Click extension icon
2. Click "Extract & Summarize" button
3. Choose: PDF, YouTube, or Text
4. Upload/paste content
5. Review results in panel
6. Copy or Download
```

### PDF Tab
```
1. Drag & drop PDF OR click to select
2. Wait for extraction
3. Results appear automatically
```

### YouTube Tab
```
1. Paste YouTube URL
2. Click "Extract & Summarize"
3. Get 6 key points + 3 suggestions
```

### Transcript Tab  
```
1. Paste text (100+ characters)
2. Click "Summarize"
3. Review formatted output
```
